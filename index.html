About TOON Format

TOON (Typed Object Oriented Notation) is a data serialization format that extends JSON with type information and additional metadata. This converter transforms standard JSON into TOON format while preserving data structure and adding type annotations.

Example

JSON: 
{
  "name": "John",
  "age": 30,
  "active": true
}
TOON: 
{
  "name": {"type": "string", "value": "John"},
  "age": {"type": "number", "value": 30},
  "active": {"type": "boolean", "value": true}
}
